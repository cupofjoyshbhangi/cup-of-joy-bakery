# Cup of Joy Bakery website

A responsive, vintage-style bakery website made with plain HTML, CSS and JavaScript.

## Files
- `index.html` — page content and menu items
- `style.css` — vintage styling and responsive layout
- `script.js` — mobile navigation, menu enquiry shortcuts and WhatsApp enquiry form

## Before publishing
1. Open `script.js` and replace `910000000000` with your WhatsApp number, using country code and digits only. For India, use `91` followed by your number. Do not include `+`, spaces or hyphens.
2. In `index.html`, replace the demo email `hello@cupofjoy.example` and the location text with your real details.
3. Update the sample product names, descriptions and prices. The listed prices are examples, not verified business prices.
4. Preview `index.html` in a browser. An internet connection is needed for Google Fonts and the remote product photos.
5. Check every image and link before sharing the site. You can replace image URLs in `index.html` with your own bakery photos.

## Free publishing with GitHub Pages
1. Create/sign in to a GitHub account at https://github.com/.
2. Create a new **public** repository, for example `cup-of-joy-bakery`.
3. Upload `index.html`, `style.css`, and `script.js` to the repository root.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/(root)`, then Save.
6. Wait for the deployment to finish. The Pages section will show your live website URL.
7. Test the website on your phone and computer.

GitHub Pages hosting is free for public repositories. A custom domain is optional and normally costs money. GitHub Pages publishes a static website, so this enquiry form sends a prepared message to WhatsApp; it does not store submissions or process payments. A customer must send the message in WhatsApp, and an order is not confirmed until you reply.

## Other free option
You can also try Netlify Drop at https://app.netlify.com/drop by dragging the folder containing these three files into the page. Free-plan terms may change.

## Notes
- Remote images are used as placeholders and need an internet connection.
- This site has no checkout, delivery scheduling, or payment processing.
- Replace all sample contact details and test the WhatsApp link before sharing publicly.
